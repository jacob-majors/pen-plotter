Sources & Credits

Plotter is built on the shoulders of incredible open-source projects. Below are all the libraries, tools, and research that made it possible.

Computer Vision & AI
MediaPipe Face Landmarker by Google

Real-time face landmark detection with 478 points and facial blendshape scores. Powers head pose estimation and blink/mouth detection.

Apache 2.0
↗
MediaPipe Gesture Recognizer by Google

Pre-trained hand gesture recognition model detecting thumbs up, peace sign, fist, open palm, and more.

Apache 2.0
↗
OpenCV (cv2) by OpenCV Team

Open source computer vision library used for webcam capture, frame processing, and image manipulation.

Apache 2.0
↗
MediaPipe Python Tasks API by Google

The Task API used to run FaceLandmarker and GestureRecognizer in VIDEO mode for real-time processing.

Apache 2.0
↗
Application Framework
PyQt6 by Riverbank Computing

Python bindings for the Qt6 application framework. Used to build the desktop GUI, camera preview widget, and system tray integration.

GPL v3
↗
Qt6 by The Qt Company

Cross-platform application and UI framework underlying PyQt6.

LGPL v3
↗
Python by Python Software Foundation

Primary programming language. Python 3.11+ used for all application logic, threading, and data processing.

PSF License
↗
Input Control
pynput by Moses Palmér

Cross-platform library for controlling and monitoring keyboard and mouse input. Used to emit real keypresses and mouse events to any application.

LGPL v3
↗
