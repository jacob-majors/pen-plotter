Pen Lift Mechanism

ACRO-INSPIRED · LINEAR RAILS + ELASTIC BAND · SERVO LIFT · ENDER 3 X-CARRIAGE

Recommended · ACRO-Inspired

Design A — Linear Rails + Elastic Band

Two 8mm linear rods with LM8UU bearings carry a sliding pen carriage. An elastic hair band pulls pen down for consistent drawing pressure. Servo lifts pen up between strokes. Based on the Tech2C/schemeandplot ACRO design.

+ Linear rails = virtually zero friction — smooth, repeatable
+ Elastic band gives consistent paper pressure (not servo-angle dependent)
+ Proven design — exactly what the ACRO Instructables uses
+ Pen swappable — just loosen clamp bolt
− Needs 2× LM8UU bearings + 8mm rod (cheap, ~$3 total)
− Pen is DOWN by default — add a hard stop or endstop to avoid dragging on power-on
Based on: Tech2C Thingiverse thing:2459624 + schemeandplot ACRO mod · 55mm × 8mm rods · SG90 servo
Alternative · Simpler Build

Design B — Spring-Loaded Cam

Single printed housing with a vertical bore. Pen spring pushes pen UP by default — safe on power loss. Servo cam arm rotates to push a guide pin (and pen) down to draw.

+ No linear rails needed — single printed housing
+ Pen UP by default (spring) — safe on power loss
+ Fewer parts, faster to build
− Printed bore has more friction than LM8UU bearings
− Pen pressure not spring-controlled — depends on servo angle
Our original design · Uses coil spring from pen · M280 Marlin servo command
